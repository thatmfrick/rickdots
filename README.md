# rickdots
- Collection of dotfiles based on Kanagawa dragon theme and CascadiaCode NF.
  - neovim
  - tmux
  - bash
  - fuzzel
  - yazi
  - eza
  - noctalia
  - niri
  - fastfetch
  - ghostty
